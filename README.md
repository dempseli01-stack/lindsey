# lindsey

PowerPoint presentation for Lindsey.

## Files

- `Lindsey_Presentation.pptx` — the finished deck (widescreen 16:9)
- `create_presentation.py` — script that regenerates the deck

## Regenerate

```bash
pip install python-pptx
python3 create_presentation.py
```
