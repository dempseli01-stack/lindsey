## Competitive landscape (product shapes)

| Tool | Shape | When it wins |
|------|-------|--------------|
| Cursor | AI-native IDE + agents + enterprise platform | Standardize / govern day-to-day coding + agent workflows |
| GitHub Copilot | IDE plugin / extension; GitHub ecosystem | Familiar toolchain, GitHub Enterprise, lower friction |
| Windsurf | AI-native IDE challenger (Cascade) | Guided agent UX / experimentation |
| Claude Code | Terminal-first agent | Deep Claude-driven workflows without editor lock-in |
| Codex | OpenAI agentic / often cloud-async | Async “go do this” tasks in OpenAI ecosystem |
| Tabnine / Amazon Q / JetBrains AI | Privacy / AWS / JetBrains niches | Air-gapped, AWS-deep, or JetBrains-committed teams |

## Cursor win formula

**Workflow · Context · Execution**

Four differentiators (lead with one):
1. Model neutrality
2. Large codebase performance / harness quality
3. Faster time to value
4. Platform across the SDLC (Bugbot, Agent Review, Automations)

Surfaces: IDE · CLI · Automations · Cloud Agents

## Competitive frames

- **vs Copilot:** snippet help → task completion; local → codebase context; point solution → integrated experience
- **vs Claude Code:** don’t trash-talk; edge = neutrality, SDLC integration, large/messy repos, team time-to-value
- **vs Windsurf:** Cursor = enterprise/platform depth; Windsurf = Cascade agent UX challenger
- **Real enterprise competitor often:** ungoverned shadow AI / do-nothing

## Enterprise 3 buckets

1. Productivity — AI-native IDE, multi-file agents, codebase context
2. Governance — SSO, SCIM, RBAC, audit logs, admin controls
3. Privacy & security — Privacy Mode / ZDR, SOC 2 Type II, CMEK, model controls

## Customer proof (use carefully)

- **Coinbase:** 2,400+ developers; 75% PRs by agents; ~7 hrs/week saved; some teams idea→prod ~20→1.8 days
- **Stripe:** 3,000+ engineers; rules + adapted review; standardized rollout
- **PayPal:** Java upgrade 8–12 months → 2 months; high-impact teams to daily deploys
